### ☁️ AWS • Currently Expanding My Knowledge

Atualmente estou aprofundando meus conhecimentos no ecossistema **Amazon Web Services (AWS)**, buscando evoluir da operação de infraestrutura para uma visão cada vez mais ampla de **arquitetura, segurança, governança, automação e otimização de custos**.

Principais áreas de estudo e prática:

- 🖥️ **Compute:** EC2
- 📦 **Storage:** S3
- 🔐 **Identity & Security:** IAM
- 🌐 **Networking:** VPC e fundamentos de redes em Cloud
- 📊 **Monitoring & Observability:** CloudWatch
- 💰 **Cost Optimization:** análise de utilização e otimização de recursos
- ⚙️ **Automation & DevOps:** integração de ambientes AWS com pipelines e processos automatizados
- 🏗️ **Architecture:** boas práticas de disponibilidade, escalabilidade, segurança e governança

> Meu objetivo não é apenas aprender serviços AWS individualmente, mas entender como utilizá-los em conjunto para construir e operar ambientes seguros, eficientes e sustentáveis.
